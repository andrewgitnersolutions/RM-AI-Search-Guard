# 04 — Google Admin Console Deployment Runbook (K-12 IT Guide)

**Audience:** Google Workspace for Education Super Admins & District IT Directors  
**Time to Deploy:** ~15 minutes for all 4 grade bands (`K-2`, `3-5`, `6-8`, `9-12`)  
**Hosting Cost:** \$0.00 | **Third-Party DPA Needed:** None (Zero PII; nothing is sent off the device)

---

## Overview: Two Settings Per Grade-Band OU

Because Chrome separates **native browser chrome** (Omnibox address bar & New Tab Page) from **web page content** (`google.com`), complete protection pairs two quick per-OU controls in Google Admin Console:

1. **Native Chrome Policy (`AIModeSettings = 1`)** → Removes Chrome's native Omnibox & New Tab Page AI Mode buttons *(Chrome / ChromeOS 138+)*.
2. **RaiseMark Extension + Grade-Band JSON Policy** → Suppresses AI Overviews, hides Google homepage/search AI Mode buttons & tabs, silently redirects `?udm=50` and `google.com/ai` / `google.com/aimode` (preserving the student's search query on `/aimode?q=…` and catching in-page single-page-app switches into AI Mode, as well as Omnibox fallback clicks on older Chromebooks), and optionally enforces classic `udm=14` Web-only search.

> **Supported Chrome Versions:** The extension requires **Chrome / ChromeOS 134 or later** (`minimum_chrome_version: "134"`). On older devices Chrome will not install it at all. Typically these are Chromebooks past their Auto Update Expiration, or devices pinned to an old version with a target-version policy. Those devices get **no** extension protection. Full two-layer protection (Step 1 + Step 2) needs **138 or later**, because the native AI Mode setting only exists from 138. All browser APIs and CSS features used in the extension are well below the 134 floor (`chrome.storage` Promises: 95; `declarativeNetRequestWithHostAccess`: 96; `@layer` and `chrome.runtime.sendMessage` Promises: 99; `hidden="until-found"`, `beforematch`, and the Navigation API: 102; `:has()`, container queries, and `Element.checkVisibility()`: 105; `:user-invalid`: 119).

> **Fail-Safe Notice:** If you force-install RaiseMark *before* pasting a Policy JSON—or accidentally paste invalid JSON—the extension automatically enters **Strict Maximum Lockdown** (all 6 protections ON) until valid JSON is saved. Students can't change anything in this state: the Options page shows **"Managed by Your School (No Grade-Band Policy Yet)"** with every switch disabled, and the toolbar popup shows "Managed by your school".
>
> **Local test toggles** (Options → Status & Local Testing) only work on a copy IT installs itself: loaded unpacked, or added from the Chrome Web Store by hand on an unmanaged profile. A force-installed copy is always locked, with or without a policy.

## Step 1: Disable Native Omnibox & New Tab Page AI Mode Buttons (Per Grade OU)

Repeat for each student Organizational Unit (e.g., `Students > K-2`, `Students > 3-5`, `Students > 6-8`, and optionally `Students > 9-12`):

1. Open [admin.google.com](https://admin.google.com).
2. Navigate to **Devices → Chrome → Settings → Users & browsers**.
3. Select the target grade-band **Organizational Unit (OU)** on the left.
4. Scroll to the **Generative AI** section (or search for **`AI Mode`**).
5. Open **Google AI Mode integrations** (Chrome policy name `AIModeSettings`).
6. Choose **Do not allow AI Mode integrations** (`1`) for grades where address-bar / New Tab page AI Mode should be removed, or **Allow AI Mode integrations** (`0`) where permitted.
7. Click **Save** (or **Override** for child OUs).

*Notes from Google's documentation:*
- *If you leave this setting unset, it follows the **Generative AI policy defaults** setting in the same section. Set it explicitly so the result doesn't change when you edit the defaults.*
- *It applies only when Google is the user's default search engine.*
- *A separate setting, **Google AI Mode content sharing**, controls sharing page and file content with AI Mode from Chrome's side panel. Consider setting it too.*
- *Chrome / ChromeOS 134–137 devices can run the extension but don't have this setting. On those devices the native button stays visible, but Step 2's extension still silently redirects any click on it to standard Google Search.*

## Step 2: Force-Install RaiseMark

1. In Google Admin Console, navigate to **Devices → Chrome → Apps & extensions → Users & browsers**.
2. Select your root **Students** OU (or individual grade-band OUs).
3. Click the **+** button → **Add from Chrome Web Store** → search for **RaiseMark: AI Search Controls for K-12** (or **Add by Chrome app or extension ID** once published).
4. Change the Installation Policy to **Force install** (prevents students from disabling or removing the extension).
5. Click **Save**.

## Step 3: Paste Per-Grade-Band Policy JSON

Select each grade-band OU on the left, click **RaiseMark: AI Search Controls for K-12**, scroll to **Policy for extensions**, and paste the JSON generated by our **4-Band Admin Policy Generator** (or customize the presets below).

### Preset A — Grades K–2 (Maximum Lockdown)
Hides AI Overviews, AI Mode buttons/tabs, auxiliary AI/Labs/Lens, redirects all AI Mode URLs, and enforces classic Web-only (`udm=14`) results while keeping Images/Videos working.
```json
{
  "gradeBand": { "Value": "K-2" },
  "masterEnabled": { "Value": true },
  "hideAiOverviews": { "Value": true },
  "hideAiModeUi": { "Value": true },
  "blockAiModeNavigation": { "Value": true },
  "forceWebOnlySearch": { "Value": true },
  "hideAuxiliaryAiFeatures": { "Value": true }
}
```

### Preset B — Grades 3–5 (Maximum Lockdown — Elementary Research)

```json
{

  "masterEnabled": { "Value": true },
  "hideAiOverviews": { "Value": true },
  "hideAiModeUi": { "Value": true },
```

Allows AI Overviews for source-critique lessons while keeping full conversational AI Mode (`udm=50` & AI Mode tab) turned off—or set `"masterEnabled": { "Value": false }` to allow everything while keeping the extension installed for instant toggle-back.
```json
{

  "masterEnabled": { "Value": true },
  "hideAiOverviews": { "Value": false },
```

> **Using Google Groups for Exceptions:** If you want an AP Computer Science class or special-education cohort across multiple grades to receive a different policy, apply a separate **Policy for extensions** to a **Configuration Group**—Google Admin Console Group policies automatically override OU policies.

### Optional Hotfix Selectors (`extraHideSelectors`) & Supported UI Languages

* **Supported Google UI Languages:** Text- and `aria-label`-based hiding covers **English** (`en*`) and **Spanish** (`es*`, including `es-419` and `es-US`). On any other Google UI language, language-neutral DOM attributes and `?udm=50` / `/aimode` URL redirects still apply, and **IT Diagnostics** logs `WARN_UNSUPPORTED_UI_LANGUAGE` once per language per day.
* **Emergency Hotfix Selectors (`extraHideSelectors`):** If Google changes its Search markup before an extension release ships, open **Options → 4-Band Admin Policy Generator → Advanced: Extra Hide Selectors (Hotfix)** (or add `"extraHideSelectors"` to your Admin Console JSON) to push up to 20 CSS selectors per category (`overview`, `aimode`, `aux`; max 300 chars each). Only filled categories are emitted, and every matched element still passes through the Organic Results Safety Guard (`isUnsafeToHide`).
  ```json
  "extraHideSelectors": {
    "Value": {
      "overview": ["div.example-ai-box"],
      "aimode": [],
      "aux": []
    }
  }
  ```

## Step 4: Usage Counts Stay on Each Device

District-wide Google Sheets analytics were removed on 2026-11-20 (owner decision D6): an extension can't hold a secret, so the endpoint couldn't tell real reports from fake ones, and restricting it to district sign-in would have tied every report to a student account. There is nothing to set up for this step.

Each Chromebook still keeps its own aggregate counters (AI Overviews hidden, AI Mode redirects, and so on) and diagnostic codes. The UI-hiding counters (`OverviewsHidden`, `AiModeUiHidden`, and `AuxAiHidden`) count searches/pages where at least one element of that category was hidden (at most once per page, regardless of Google DOM re-renders) and flush to local storage when leaving or hiding a tab or every 10 seconds. IT staff can view them on the device under **Options → IT Diagnostics** and export them with **Export Local Metrics CSV**. Nothing is sent off the device. If an older policy JSON still contains `analyticsEnabled`, `analyticsEndpointUrl`, `analyticsSharedToken` or `analyticsFlushIntervalMinutes`, remove those fields: they are no longer in the policy schema and the extension ignores them.

## Step 5: Verification Checklist (On a Test Student Chromebook)

1. Open `chrome://policy` → click **Reload policies**.
   * Confirm `AIModeSettings` = `1` (for restricted OUs).
   * Scroll to **Extension policies** → confirm **RaiseMark: AI Search Controls for K-12** shows `Status: OK` with the expected grade-band JSON.
2. Click the extension toolbar icon → confirm it displays **only** `"Managed by your school"`.
3. Open a new tab and test:
   * Search `"what is photosynthesis"` → confirm **no AI Overview** and **no AI Mode tab**, and organic search links load normally.
   * Navigate directly to `https://www.google.com/search?q=photosynthesis&udm=50` → confirm silent redirect to clean search preserving `q=photosynthesis`.
   * Navigate directly to `https://www.google.com/ai` → confirm silent redirect to `https://www.google.com/`.
   * Navigate directly to `https://www.google.com/aimode?q=photosynthesis` → confirm silent redirect to ordinary search results for `photosynthesis` (the student's search is kept; Web-only `udm=14` is added when `forceWebOnlySearch` is ON).
   * Click the **Images** tab (`udm=2`) → confirm Images load normally even when `forceWebOnlySearch` is ON.
4. Visit `chrome-extension://<EXTENSION_ID>/ui/options.html` → **IT Diagnostics** tab → confirm zero `ERR_*` entries and active counters incrementing. On a managed device **Reset Local Counters** is disabled (students can't wipe the counters); IT can still reset them on an unmanaged test install.

## Troubleshooting Quick Reference

| Diagnostic Code | Meaning | Fix |
| :--- | :--- | :--- |
| `WARN_OMNIBOX_POLICY_MISSING` | Student clicked Chrome's native Omnibox/NTP AI button; extension blocked it, but button is still visible. | Enable `AIModeSettings = 1` in Step 1 for this OU (requires ChromeOS/Chrome 138+). |
| `WARN_NO_MANAGED_POLICY` | Extension is running on Strict Maximum Lockdown defaults because Admin Console JSON wasn't pushed yet. | Paste valid JSON in **Policy for extensions** and run `chrome://policy` → Reload policies. |
| `ERR_POLICY_INVALID` | Syntax/type error in Admin Console JSON (e.g., missing `{"Value": ...}` wrapper or string `"true"` instead of boolean `true`). | Re-generate JSON via the **Admin Policy Generator** tab and re-save. |
| `ERR_DNR_SYNC_FAILED` | Chrome rejected a `declarativeNetRequest` dynamic redirect rule update. | Reload the extension or verify Chrome / ChromeOS is 134+. If persistent, copy diagnostic JSON and email RaiseMark Support (`info@raisemarkai.com`). |
| `ERR_SELECTOR_SYNTAX` | A bundled or custom `extraHideSelectors` CSS selector failed browser syntax validation. | Check any custom selectors pushed in `extraHideSelectors` (or update the extension); valid selectors continue running. |
| `ERR_SAFETY_GUARD_TRIPPED` | Google changed Search DOM structure; safety guard protected organic results. | Check Chrome Web Store for a selector update or report diagnostic JSON to RaiseMark Support (`info@raisemarkai.com`). |
| `ERR_STORAGE_FAILURE` | Extension storage (`chrome.storage.local` or `chrome.storage.managed`) read/write failed. | Check Chrome profile disk quota or reload the browser/profile. |
| `WARN_AI_SURFACE_VISIBLE` | A visible AI heading or AI Mode button remained unhidden after a sweep (`detail` shows category only). | Check for an extension update, or push temporary hotfix CSS selectors via managed `extraHideSelectors`. |
| `WARN_UNSUPPORTED_UI_LANGUAGE` | Google Search rendered in a UI language outside English and Spanish (`detail` shows primary subtag). | Structural selectors and AI Mode URL redirects remain active; label-based fallbacks cover English and Spanish only. |

## What This Extension Does Not Cover

By design, several surfaces and browser modes sit outside a Chrome extension's sandbox or this project's least-privilege scope. Pair the companion Google Admin Console settings below for complete student-OU coverage:

| Gap / Surface | Why the Extension Doesn't Cover It | Recommended Admin Console Companion Setting |
| :--- | :--- | :--- |
| **Incognito windows** | Force-installed extensions are disabled in Incognito windows by default unless allowed, and Incognito bypasses normal profile history. | Set **`IncognitoModeAvailability`** = **`1`** (*Disallow incognito mode*) under **Devices → Chrome → Settings → Users & browsers** for student OUs. |
| **Guest mode sessions** | Extensions do not run inside ChromeOS Guest sessions or desktop Chrome Guest profiles. | Disable Guest mode on **ChromeOS / Chromebooks** via **`DeviceGuestModeEnabled`** = **`false`** (**Devices → Chrome → Settings → Device settings**), and on **managed desktop Chrome (Windows, macOS, Linux)** via **`BrowserGuestModeEnabled`** = **`false`** (**Devices → Chrome → Settings → Users & browsers**). |
| **Other browsers, unmanaged profiles, & personal devices** | Manifest V3 policies apply only to managed Chrome / ChromeOS profiles where the extension is force-installed. | Enforce managed sign-in / browser management on district-owned devices; non-managed browsers (Safari, Firefox, Edge) and personal profiles are out of reach. |
| **Non-`google.com` country Google domains (`google.co.uk`, `google.ca`, etc.)** | Excluded intentionally (`docs/01 §3.2`) to keep extension `host_permissions` strictly scoped to `https://www.google.com/*` and `https://google.com/*`. | Not covered by this extension; districts outside `google.com` must evaluate domain coverage before rollout. |
| **Gemini web app (`gemini.google.com`) & Gemini in Chrome** | Standalone Gemini web chat and Chrome's built-in Gemini browser integrations are separate from Google Search. | Set **Generative AI → Gemini app → Service status** to **Off** for the target OU, which controls **`gemini.google.com`**. Disable **Gemini in Chrome** via Chrome Enterprise policy **`GeminiSettings`** = **`1`** (*Do not allow Gemini integrations* under **Devices → Chrome → Settings → Users & browsers → Generative AI**; unset GenAI policies inherit from **`GenAiDefaultSettings`**). |
| **Chrome Omnibox & New Tab Page native AI Mode button** | Native browser UI cannot be modified by extension content scripts or CSS. | Pair with **`AIModeSettings`** = **`1`** (Chrome/ChromeOS 138+) in Step 1 above. On Chrome 134–137 or if `AIModeSettings` is omitted, clicks still hit the extension's DNR redirect and log `WARN_OMNIBOX_POLICY_MISSING`. |

## Scope, Best-Effort UI Control & Non-Affiliation Notice

* **Pedagogical UI Control (Not a Content Filter):** RaiseMark: AI Search Controls for K-12 helps districts manage generative AI features on Google Search by grade band. It is **not** a CIPA content filter, web filter, or student-safety monitoring tool. Because Google Search HTML and URL parameters are controlled by Google LLC and may change at any time without notice, UI hiding and URL redirection operate on a best-effort basis with an automatic Organic Results Safety Guard (`isUnsafeToHide`) and a 1-click Google Admin Console kill switch (`"masterEnabled": { "Value": false }`).
* **Non-Affiliation:** RaiseMark AI is an independent organization and is not affiliated with, endorsed by, or sponsored by Google LLC.
