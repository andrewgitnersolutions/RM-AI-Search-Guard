# 04 — Google Admin Console Deployment Runbook (K-12 IT Guide)

**Audience:** Google Workspace for Education Super Admins & District IT Directors  
**Time to Deploy:** ~15 minutes for all 4 grade bands (`K-2`, `3-5`, `6-8`, `9-12`)  
**Hosting Cost:** \$0.00 | **Third-Party DPA Needed:** None (Zero PII; optional analytics stay inside your own Google Workspace)

---

## Overview: Two Settings Per Grade-Band OU

Because Chrome separates **native browser chrome** (Omnibox address bar & New Tab Page) from **web page content** (`google.com`), complete protection pairs two quick per-OU controls in Google Admin Console:

1. **Native Chrome Policy (`AIModeSettings = 1`)** → Removes Chrome's native Omnibox & New Tab Page AI Mode buttons *(Chrome / ChromeOS 138+)*.
2. **RaiseMark Search Guard Extension + Grade-Band JSON Policy** → Suppresses AI Overviews, hides Google homepage/search AI Mode buttons & tabs, silently redirects `?udm=50` and `google.com/ai` (including Omnibox fallback clicks on older Chromebooks), and optionally enforces classic `udm=14` Web-only search.

> **Fail-Safe Notice:** If you force-install RaiseMark Search Guard *before* pasting a Policy JSON—or accidentally paste invalid JSON—the extension automatically enters **Strict Maximum Lockdown** (all 6 protections ON) until valid JSON is saved.

---

## Step 1: Disable Native Omnibox & New Tab Page AI Mode Buttons (Per Grade OU)

Repeat for each student Organizational Unit (e.g., `Students > K-2`, `Students > 3-5`, `Students > 6-8`, and optionally `Students > 9-12`):

1. Open [admin.google.com](https://admin.google.com).
2. Navigate to **Devices → Chrome → Settings → Users & browsers**.
3. Select the target grade-band **Organizational Unit (OU)** on the left.
4. Search for **`AI Mode`** (or **`AIModeSettings`**).
5. Locate **Settings for Google's AI Mode integrations in the address bar and New Tab page search box**.
6. Set to **Do not allow users to use AI Mode integrations** (`1`) for grades where Omnibox/NTP AI should be removed (or **Allow** (`0`) for grades where permitted).
7. Click **Save** (or **Override** for child OUs).

*(Optional: For legacy Chromebooks below ChromeOS 138, the native button cannot be hidden by Chrome policy, but Step 2's extension will still silently intercept and redirect any clicks on it to standard Google Search.)*

---

## Step 2: Force-Install RaiseMark Search Guard

1. In Google Admin Console, navigate to **Devices → Chrome → Apps & extensions → Users & browsers**.
2. Select your root **Students** OU (or individual grade-band OUs).
3. Click the **+** button → **Add from Chrome Web Store** → search for **RaiseMark Search Guard for K-12** (or **Add by Chrome app or extension ID** once published).
4. Change the Installation Policy to **Force install** (prevents students from disabling or removing the extension).
5. Click **Save**.

## Step 3: Paste Per-Grade-Band Policy JSON

Select each grade-band OU on the left, click **RaiseMark Search Guard for K-12**, scroll to **Policy for extensions**, and paste the JSON generated by our **4-Band Admin Policy Generator** (or customize the presets below).

### Preset A — Grades K–2 (Maximum Lockdown)
Hides AI Overviews, AI Mode buttons/tabs, auxiliary AI/Labs/Lens, redirects all AI Mode URLs, and enforces classic Web-only (`udm=14`) results while keeping Images/Videos working.

## Step 4 (Optional): Enable \$0 District-Owned Google Sheets Analytics (5 Minutes)

By default (`analyticsEnabled: false`), all counters stay locally on each Chromebook with zero network traffic. To see district-wide totals (AI Overviews hidden, AI Mode attempts redirected, errors by grade band) inside your own Google Workspace:

1. Create a new **Google Sheet** in a district IT folder (e.g., `Search Guard District Analytics`).
2. Open **Extensions → Apps Script**.
3. Delete the placeholder code and paste `templates/apps-script/Code.gs` from the repository.
4. *(Optional)* Set a non-secret `SHARED_TOKEN` string at the top of `Code.gs` (e.g., `"district-sg-2026"`).
5. Click **Deploy → New deployment → Select type: Web app**:
   * **Execute as:** `Me` (service/IT account)
   * **Who has access:** `Anyone` *(required so managed Chromebooks can POST anonymous aggregate counts without interactive OAuth popups)*
6. Click **Deploy**, authorize the script to edit its own spreadsheet, and copy the resulting Web App URL (`https://script.google.com/macros/s/.../exec`).
7. Add these fields to each grade-band OU's **Policy for extensions** JSON:
   ```json
   "analyticsEnabled": { "Value": true },
   "analyticsEndpointUrl": { "Value": "https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec" },
   "analyticsSharedToken": { "Value": "district-sg-2026" },
   "analyticsFlushIntervalMinutes": { "Value": 240 }
   ```
8. **Zero PII Guarantee:** Your Google Sheet receives **only** daily aggregate rows (`Date`, `GradeBand`, `ExtensionVersion`, integer block counts, integer error counts)—never student names, emails, device IDs, or search queries.

## Step 5: Verification Checklist (On a Test Student Chromebook)

1. Open `chrome://policy` → click **Reload policies**.
   * Confirm `AIModeSettings` = `1` (for restricted OUs).
   * Scroll to **Extension policies** → confirm **RaiseMark Search Guard for K-12** shows `Status: OK` with the expected grade-band JSON.
2. Click the extension toolbar icon → confirm it displays **only** `"Managed by your school"`.
3. Open a new tab and test:
   * Search `"what is photosynthesis"` → confirm **no AI Overview** and **no AI Mode tab**, and organic search links load normally.
   * Navigate directly to `https://www.google.com/search?q=photosynthesis&udm=50` → confirm silent redirect to clean search preserving `q=photosynthesis`.
   * Navigate directly to `https://www.google.com/ai` → confirm silent redirect to `https://www.google.com/`.
   * Click the **Images** tab (`udm=2`) → confirm Images load normally even when `forceWebOnlySearch` is ON.
4. Visit `chrome-extension://<EXTENSION_ID>/ui/options.html` → **IT Diagnostics** tab → confirm zero `ERR_*` entries and active counters incrementing.

## Troubleshooting Quick Reference

| Diagnostic Code | Meaning | Fix |
| :--- | :--- | :--- |
| `WARN_OMNIBOX_POLICY_MISSING` | Student clicked Chrome's native Omnibox/NTP AI button; extension blocked it, but button is still visible. | Enable `AIModeSettings = 1` in Step 1 for this OU (requires ChromeOS/Chrome 138+). |
| `WARN_NO_MANAGED_POLICY` | Extension is running on Strict Maximum Lockdown defaults because Admin Console JSON wasn't pushed yet. | Paste valid JSON in **Policy for extensions** and run `chrome://policy` → Reload policies. |
| `ERR_POLICY_INVALID` | Syntax/type error in Admin Console JSON (e.g., missing `{"Value": ...}` wrapper or string `"true"` instead of boolean `true`). | Re-generate JSON via the **Admin Policy Generator** tab and re-save. |
| `ERR_ANALYTICS_FLUSH_FAILED` | District Google Apps Script returned an error or redirect auth screen. | Re-deploy Apps Script with **Who has access: Anyone** and ensure `analyticsSharedToken` matches `Code.gs`. |
| `ERR_SAFETY_GUARD_TRIPPED` | Google changed Search DOM structure; safety guard protected organic results. | Check Chrome Web Store for a selector update or report diagnostic JSON to RaiseMark Support. |
